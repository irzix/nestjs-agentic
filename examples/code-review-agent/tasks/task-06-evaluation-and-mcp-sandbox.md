# Task 06: Evaluation Quality Gates & Model Context Protocol (MCP) Sandbox

> **Implementation specification for Position-Debiased LLM-as-a-Judge, Docker MCP Test Sandboxes, and GitHub Octokit Tools.**

---

## 🎯 Objective
Implement the pre-egress quality evaluation gate that eliminates hallucinated line references and position bias, alongside the Docker MCP client provider that executes sandboxed test suites and compiler checks.

---

## 📁 Target Files to Create
* `src/evaluation/review-quality-evaluator.service.ts`
* `src/evaluation/diff-boundary-validator.ts`
* `src/tools/sandbox-mcp.provider.ts`
* `src/tools/github-octokit.tools.ts`

---

## 📋 Detailed Technical Requirements

### 1. Diff Boundary Validator (`src/evaluation/diff-boundary-validator.ts`)
* Parse unified git diff into valid `(filePath, lineRange)` lookup tables.
* Assert that 100% of inline comments generated by agents reference lines that genuinely exist in the modified diff.
* Automatically drop or adjust out-of-boundary line references.

### 2. Position-Debiased LLM Judge (`src/evaluation/review-quality-evaluator.service.ts`)
* Implements the pairwise debiasing protocol from *Zheng et al. (UC Berkeley LMSYS)*:
  * Run evaluation in forward candidate order (`score1`).
  * Run evaluation in reverse candidate order (`score2`).
  * Compute final score: $\text{FinalScore} = \frac{\text{score1} + \text{score2}}{2}$.
* Assert 3 rubric criteria: Line Existence (Fatal if false), Actionability ($\ge 0.8$), Constructive Tone ($\ge 0.8$).

### 3. Docker MCP Tool Provider (`src/tools/sandbox-mcp.provider.ts`)
* Connect to isolated Docker MCP server via `StdioClientTransport`.
* Expose tool: `execute_sandboxed_command({ command: string })`.
* Execute `tsc --noEmit` and `jest --findRelatedTests` inside ephemeral disposable container.

### 4. GitHub Octokit Tools (`src/tools/github-octokit.tools.ts`)
* Provide `@ToolSet` with:
  * `fetch_pr_diff(repo, prNumber)`
  * `post_inline_review_comment(path, line, body)`
  * `post_pr_summary_review(overallStatus, summaryMarkdown)`
  * `git_create_branch_and_commit(branchName, patches)` (governed by approval policy).

---

## ✅ Acceptance Criteria & Testing
1. Review comments referencing nonexistent line numbers are trapped and corrected before posting.
2. Position-debiased judge calculates symmetric scores regardless of candidate presentation order.
3. Sandbox MCP tool executes tests without host process escape.
4. Unit tests pass: `npm run test:unit -- src/evaluation src/tools`
