## BenchmarkRunner

`BenchmarkRunner` takes a registered `AgentRunner` and runs a dataset of `EvalDatasetItem`s against a named agent, scoring each with the configured `EvalMetric`s (defaults: `SafetyPolicyMetric`, `AccuracyGroundTruthMetric`, `ExecutionEfficiencyMetric`):

```typescript
import { BenchmarkRunner, ToolPrecisionMetric } from '@nestjs-agentic/evaluation';

const runner = new BenchmarkRunner(agentRunner, {
  metrics: [new ToolPrecisionMetric(), new AccuracyGroundTruthMetric()],
  trialsPerItem: 1,
});

const summary = await runner.runBenchmark('codeReviewAgent', [
  {
    id: 'test_sql_injection',
    query: 'Review diff with raw query string interpolation',
    expectedToolSequence: ['flagVulnerability'],
    forbiddenTools: ['deleteFile'],
  },
]);

console.log(summary);
```

Retrieval-specific metrics (recall@k, nDCG, faithfulness) evaluated against a `RAGPipeline`/`KnowledgeBase` rather than an `AgentResult` are not implemented yet — tracked in [issue #143](https://github.com/irzix/nestjs-agentic/issues/143).
