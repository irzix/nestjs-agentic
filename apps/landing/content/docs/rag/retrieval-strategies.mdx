## Modular Retrieval Strategies

`@nestjs-agentic/rag` supports pluggable retrieval strategies:

### 1. `QueryExpansionStrategy`
A pre-retrieval strategy that expands the raw query via a synonym dictionary (`synonymsMap`), a custom function (`expandQueryFn`), or an LLM-driven paraphraser (`useLLM` + `llmProvider`).

### 2. `LateChunkingStrategy`
Blends a document-level global embedding into each chunk vector to preserve full-document context in chunk-level similarity.

### 3. `ParentChildHydrationStrategy`
Works with chunks produced by `ParentChildSplitter`: indexes small sub-chunks (methods, paragraphs) for high vector search precision, but hydrates the full parent text (carried in `chunk.metadata.parentText`) when constructing the final context prompt.

### 4. `MmrStrategy`
A post-retrieval diversity strategy implementing Maximal Marginal Relevance: greedily selects chunks that are relevant to the query but dissimilar to chunks already selected, so near-duplicate results (e.g. overlapping parent/child chunks) don't crowd out distinct context.

```typescript
import { MmrStrategy } from '@nestjs-agentic/rag';

const mmr = new MmrStrategy({
  topK: 5,
  lambda: 0.5, // 1 = pure relevance, 0 = pure diversity
});
```

Requires chunk embeddings to diversify by; chunks without one pass through unranked. Relevance comes from `context.scores` (populated by `RAGPipeline` during retrieval).

Strategies aren't passed to `KnowledgeBase` directly — they're registered on a `RAGPipeline`, which runs pre-retrieval strategies, retrieves via the `KnowledgeBase`, then runs post-retrieval strategies:

```typescript
import {
  KnowledgeBase,
  RAGPipeline,
  QueryExpansionStrategy,
  ParentChildHydrationStrategy,
} from '@nestjs-agentic/rag';

const kb = new KnowledgeBase({ vectorStore: hybridStore });

const pipeline = new RAGPipeline({
  knowledgeBase: kb,
  strategies: [
    new QueryExpansionStrategy({ synonymsMap: { checkout: ['payment', 'order'] } }),
    new ParentChildHydrationStrategy(),
  ],
});

const context = await pipeline.executePipeline('Find order checkout verification methods');
```
