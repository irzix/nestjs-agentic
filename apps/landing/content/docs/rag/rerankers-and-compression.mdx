## Reranking

Bi-encoder vector search produces candidate matches quickly, but computes query and document embeddings independently, which caps precision.

`RerankerStrategy` is a post-retrieval pipeline stage that delegates scoring to a `rerankFn` you supply — call a Cohere Rerank, HuggingFace cross-encoder, or any other endpoint from it:

```typescript
import { RerankerStrategy } from '@nestjs-agentic/rag';

const reranker = new RerankerStrategy({
  rerankFn: async (query, chunks) => {
    // Call your reranker endpoint; return one score per chunk, same order.
    return chunks.map((c) => scoreFor(query, c));
  },
  topK: 3,
});
```

No reranker provider ships built-in today — if `rerankFn` is omitted, or throws, `RerankerStrategy` falls back to a term-overlap heuristic. Built-in Cohere/Voyage adapters and a `minScore` cutoff are tracked in [issue #132](https://github.com/irzix/nestjs-agentic/issues/132).

## Contextual Compression

`ContextualCompressionStrategy` trims boilerplate, comments, and unreferenced lines from retrieved passages before injecting them into the system prompt, keeping token usage minimal.
