## Reranking

Bi-encoder vector search produces candidate matches quickly, but computes query and document embeddings independently, which caps precision.

`RerankerStrategy` is a post-retrieval pipeline stage that delegates scoring to a `rerankFn` you supply. Built-in factories ship for Cohere Rerank and Voyage AI Rerank, or you can pass any other endpoint as a closure:

```typescript
import { RerankerStrategy, createCohereRerankProvider } from '@nestjs-agentic/rag';

const reranker = new RerankerStrategy({
  rerankFn: createCohereRerankProvider({ apiKey: process.env.COHERE_API_KEY }),
  topK: 3,
  minScore: 0.3, // drop chunks below this relevance score entirely, instead of just deprioritizing them
});
```

`createVoyageRerankProvider` works the same way against the Voyage AI Rerank API.

If `rerankFn` is omitted, `RerankerStrategy` uses a term-overlap heuristic. If `rerankFn` throws, it invokes `onRerankFailure` when configured, then either falls back to that same heuristic when `onRerankFailureMode` is `'fallback'` (default) or rethrows when it is `'throw'`:

```typescript
const reranker = new RerankerStrategy({
  rerankFn: myRerankFn,
  onRerankFailure: (err) => logger.warn('Reranker failed', err),
  onRerankFailureMode: 'throw', // or 'fallback' (default) to continue with term-overlap scoring
});
```

## Contextual Compression

`ContextualCompressionStrategy` trims boilerplate, comments, and unreferenced lines from retrieved passages before injecting them into the system prompt, keeping token usage minimal.

Retrieved content is untrusted — it may come from an ingested document an attacker controls — so `ContextualCompressionStrategy` and `UShapedContextStrategy` both wrap each chunk's content in a `<retrieved_chunk>` boundary tag and strip known injection delimiters (via `@nestjs-agentic/core`'s `PromptInjectionSanitizer`) before writing `compressedContext`. This mitigates indirect prompt injection carried through poisoned documents (see [Governance and Policies](/docs/core/governance-and-policies) for the same mitigation applied to tool output).
