## Overview

Monolithic single-agent prompts become brittle as task complexity scales.

`@nestjs-agentic/orchestration` enables modular **Multi-Agent Networks** where specialized worker agents collaborate under defined architectural topologies:

1. **Hierarchical Supervisor-Worker**: A lead synthesizer delegates discrete sub-tasks to specialists and compiles their findings.
2. **Parallel Fan-Out**: Running multiple specialists concurrently with zero blocking latency.
3. **Iterative Refinement Loops**: Feedback loops where a critic agent reviews and refines a worker agent's output until acceptance criteria are satisfied.
4. **Multi-Agent Dialectic Debate**: Two or more specialist agents challenge each other's conclusions in structured rounds.
5. **Consensus Convergence**: Statistical evaluation of inter-agent agreement using Fleiss' Kappa.
