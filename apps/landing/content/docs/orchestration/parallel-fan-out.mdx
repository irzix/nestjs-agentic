## ParallelSubAgentRunner

When analyzing multi-dimensional inputs (such as pull requests with security, architecture, and test coverage concerns), running specialists sequentially wastes precious seconds.

`ParallelSubAgentRunner` takes the shared `AgentRunner` and delegates a list of `SubAgentTask`s (each naming a registered sub-agent by `agentName`), fanning them out concurrently according to `aggregationStrategy` (`allSettled`, `firstSuccess`, `fallbackChain`, `bestOf`, or `consensusMerge`):

```typescript
import { ParallelSubAgentRunner } from '@nestjs-agentic/orchestration';

const runner = new ParallelSubAgentRunner(agentRunner, {
  aggregationStrategy: 'allSettled',
  timeoutMs: 30000,
  maxConcurrency: 3,
});

const { results, combinedResponse, successCount, failedCount } = await runner.run(parentContext, [
  { agentName: 'securitySpecialist', message: prDiff },
  { agentName: 'architectureSpecialist', message: prDiff },
  { agentName: 'qualitySpecialist', message: prDiff },
]);

for (const result of results) {
  if (result.status === 'success') {
    console.log(`${result.agentName}: ${(result.score ?? 0) * 100}%`);
  }
}
```
