## Variance-Based Consensus Scoring

`DebateRunner.calculateConsensusScore()` measures agreement among debaters' confidence scores for a round using normalized variance, not Fleiss' Kappa — Fleiss' Kappa requires categorical ratings across raters and isn't what's computed here.

```text
Variance = (1/N) * sum((s_i - mean)^2)
Consensus = 1 - Variance / MaxVariance     // MaxVariance = 0.25 for scores bounded [0, 1]
```

Debaters with no reported `score` default to a `0.5` prior confidence before the variance calculation.

### Interpretation

| Consensus Score | Meaning | `DebateRunner` behavior |
| :--- | :--- | :--- |
| **`>= consensusThreshold`** (default `0.7`) | Debaters converged | Debate ends early; highest-scoring debater's response wins |
| **`< consensusThreshold`, rounds remain** | Debaters diverge | Next round runs with the cross-critique transcript prepended |
| **`< consensusThreshold` after `maxRounds`** | No convergence reached | `requiresHumanReview: true` on the result |

```typescript
import { DebateRunner } from '@nestjs-agentic/orchestration';

const debate = new DebateRunner(agentRunner);

// calculateConsensusScore is also usable standalone against any round's results
const score = debate.calculateConsensusScore(round.results);
```

A Fleiss' Kappa-based multi-rater consensus metric, suited to independent categorical severity classifications rather than debate convergence, is tracked as possible future work and does not ship today.
