## ShortTermMemory Store

`ShortTermMemory` maintains a sliding-window record of recent turns per session, implementing the standard `AgentMemoryStore` interface (`save`/`recall`). It optionally persists through a core `StateStore` (e.g. Redis-backed) instead of an in-process fallback map:

```typescript
import { ShortTermMemory } from '@nestjs-agentic/memory';

const shortTerm = new ShortTermMemory({
  maxMessages: 10,
  // stateStore: myRedisStateStore, // optional, for cross-instance persistence
});

// Save turns
await shortTerm.save({
  id: 'turn_1',
  sessionId: 'session_42',
  type: 'short_term',
  content: 'User: What is my current balance?',
  timestamp: new Date(),
});

// Retrieve the active window for a session
const history = await shortTerm.recall('', { sessionId: 'session_42' });
```

---

## Window Pruning

`ShortTermMemory` prunes with a FIFO sliding window: once a session exceeds `maxMessages` (default `20`), the oldest records are dropped on the next `save()`. There is no built-in `summarizing_window` strategy that compresses older turns via a summarization agent — `@nestjs-agentic/memory`'s `TokenBudgetSummarizer` utility performs a simpler concatenation-based reduction and can be composed manually if that behavior is needed.
